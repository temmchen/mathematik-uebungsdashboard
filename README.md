# Mathematik Übungsdashboard

Übungsdashboard für Mathematik & MINT (Niveau 4TPST / DP1 / DP2 – Luxemburg).

Die Datei `index.html` ist die Anwendung. Über GitHub Pages aufrufbar unter:

https://temmchen.github.io/mathematik-uebungsdashboard/

Funktionen:
- 1000 Aufgaben aus 30 Kategorien (Bruchrechnung, Algebra, Geometrie, Pythagoras, Gleichungen, Prozent, Statistik …)
- 100 zufällige Aufgaben pro Sitzung
- Eingabe von Vorname, Name, Klasse und Datum (mit Maske TT.MM.JJJJ)
- Hell- / Dunkel-Modus
- PDF-Export für den Schüler zum Ausdrucken
